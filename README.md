# Dailift

운동, 식단, 몸의 변화를 한곳에 기록하는 앱 (iOS · Android).

- React Native (Expo SDK 57) · TypeScript
- 오프라인 우선: 기기의 SQLite가 정본, 계정 연결 시 서버와 동기화
- 한국어 / English

## 개발

```bash
npm install
npm run android   # Android 에뮬레이터
npm run lint      # Biome
npm run typecheck
npm test
```

문서는 [`docs/`](./docs) 폴더를 참고하세요.
