# Dailift 기능 명세

## 0. 원칙
- iOS · Android 동시 출시, 한국어/영어, 무료(수익화 없음).
- 오프라인 우선: 기기의 SQLite가 정본이고 서버(Supabase)는 복제본. 알림은 전부 로컬.
- 게스트는 기기 로컬 전용. 계정을 연결하는 시점에 서버 계정을 만들고 업로드한다.
- 루틴 하나 = 하루치 운동. 데이터에는 루틴 묶음(프로그램) 계층이 있지만 화면에서는 소제목으로만 보인다.
- PR = 최고 중량 PR + 추정 1RM PR (워밍업·미완료 세트 제외).
- 덤벨 무게 표기는 설정에서 한 손/양손 선택(기본 한 손). 무게는 입력한 단위 그대로 저장한다.
- 볼륨 계산: 워밍업 제외, 주동근 1세트 · 협응근 0.5세트. 통계는 지난 7일 기준.
- 테마: 라이트(순백 배경)/다크 × 포인트 색 모노(기본)/블루/라임. 토큰은 `src/theme/tokens.ts`.
- 운동 중 화면의 휴식 타이머는 화면 맨 아래에 붙고 내용을 덮지 않는다.
- 출시 후로 미룬 것: 커뮤니티, 루틴 공유, Apple Watch, AI 루틴, 동작 애니메이션.

## 1. 내비게이션
하단 탭 5개: 홈 · 루틴 · 기록(히스토리｜통계 세그먼트) · 영양(식단｜영양제 세그먼트) · 내 정보(체성분·사진·설정).
운동 중 화면은 탭 위에 뜨는 전체 화면. 진행 중 세션이 있으면 모든 탭 하단에 "운동 중" 미니 바.

## 3. 화면별 명세

### 3.1 로그인·계정
- 시작 화면: Apple(iOS만) / Google / 이메일 / "로그인 없이 시작". 약관·처리방침 동의 + 만 14세 이상 확인. Apple·Google 버튼 왼쪽에 공식 로고.
- 이메일: 가입(인증 메일), 로그인, 비밀번호 재설정(6자리 코드 + 링크).
- 게스트 → 계정 연결(설정). 이미 가입된 ID면 기존 계정으로 로그인 후 기기 기록 병합 흐름.
- 서버 업로드 전 건강 데이터 동의 화면(체성분·식단·사진; 개별 체크, 설정에서 철회). 화면 문구에 서비스 업체명은 쓰지 않는다.
- 로그아웃, 인앱 계정 삭제(재인증 → 확인 → 서버·로컬 삭제, Apple 토큰 revoke). 게스트는 "모든 데이터 삭제".

### 3.2 온보딩 (건너뛰기 가능, "1/4")
1 운동 경험(처음·6개월 미만·1년 이상) → 2 주 몇 번(2·3·4·5+) → 3 목표(근육·힘·체지방·꾸준히) → 4 키·체중(선택) + 바디 타입(남성형/여성형, 근육맵용).
추천이 건드리는 것은 셋뿐: 루틴 정렬("추천" 배지 1개), 부위 밸런스 권장 범위, 단백질 목표(체중 없으면 숨김). 설정에서 재응답.

### 3.3 홈
- 주간 스트립(요일 7칸: 완료/예정/오늘). 오늘 루틴 카드 → "운동 시작". 루틴 없는 날: 휴식일 + "빈 운동 시작".
- 정보 카드: 지난 7일 운동 횟수 / 주 목표, 오늘 영양제 체크, 최근 PR. 연속 기록은 "주" 단위.

### 3.4 루틴 목록
내 루틴 카드(요일, 오늘 칩, 묶음 소제목) / 추천 루틴 3개(A 전신 주3회 · B 상하체 2분할 · C 푸시풀레그; "추천" 배지 1개) / 읽기 전용 미리보기 → "내 루틴으로 복사"(원본 보존, 묶음째) / 루틴 생성 / 복제 / 묶음 순환 모드 토글.

### 3.5 루틴 편집
이름 / 요일 7칸 / 종목 추가·순서 변경(핸들)·삭제(스와이프) / 종목별 목표 세트·렙 범위·휴식·증량 단위·메모 / 루틴 알림 시각 / 루틴 삭제 / 시작 버튼 없음 / 저장 안 한 변경 이탈 시 확인.

### 3.6 종목 검색
검색(초성 지원) / 부위 필터 / 다중 선택 / "N개 추가" / 기본 34종 상단 고정 / 탭 = 선택 / 커스텀 종목: 이름, 유형(무게×횟수 · 맨몸(+추가중량)×횟수 · 시간), 주동근 필수, 협응근·기구.

### 3.7 운동 중 ★
세트 행(무게·횟수 + 완료 체크) / 자동 프리필(회색, 체크해야 기록 인정) / 휴식 타이머(맨 아래 도킹, 종료 시 진동·소리·백그라운드 알림) / 증량 제안 한 줄 / 워밍업 세트 자동 생성 + 주황 마커 / 고급 항목(RPE·세트 종류) 기본 꺼짐 / 세트·종목 추가·교체 / 세션 복구(이어하기/버리기) / PR 감지 → 빨간 PR 배지 / 원판 계산기 / 화면 꺼짐 방지(옵션) / 완료 버튼.

### 3.8 세션 요약
시간·세트·볼륨 / 근육맵 앞뒤(집중·주요·보조) / PR 목록 / 메모 / 사진 첨부(로컬).

### 3.9 히스토리
날짜별 세션 목록(왼쪽 날짜 컬럼) / 세션 상세 / 수정·삭제 / 통계와 세그먼트 전환.

### 3.10 통계 ★
지난 7일 기준 / 진행도 두 숫자 나란히(증감 색·화살표 없음) / 부위 밸런스 게이지(권장 10~20세트, 초과·미달 모두 주황) / 종목별 추정 1RM 추이 / 정체 감지 한 줄 / 주간 리포트 / 사진 비교.

### 3.11 종목 상세
포즈 이미지(시작/끝) / 설명 5단계 / 주동근·협응근(미니 근육맵) / 기구 / 추정 1RM / 개인 기록 추이.

### 3.12 영양제
등록(이름·용량·타이밍) / 시각 알림(같은 시각은 1개로 묶음) / 운동 후 N분 알림 / 활성 토글 / 오늘 복용 체크 / 미복용 알림 / 날짜별 기록. 효능 문구 없음, 면책 문구.

### 3.13 식단
날짜별 끼니 / 음식 검색(번들 DB, 오프라인) / 양 입력 / 커스텀 음식 / 즐겨찾기·최근 / 바코드(Open Food Facts) / 하루 합계 + 단백질 목표 진행 / 출처 표기.

### 3.14 체성분·사진
직접 입력 → 인바디 결과지 OCR(온디바이스, 확인 UI 필수) → HealthKit/Health Connect / 체중·골격근량·체지방률 한 그래프(kg 축 + % 축) + 사진 타임라인 / 사진 비교.

### 3.15 설정
단위 / 바 무게 / 보유 원판 / 덤벨 표기 / 기본 휴식 / 고급 기록 / 화면 꺼짐 방지 / 테마 / 포인트 색(모노·블루·라임) / 언어 / 프로파일링 재응답 / 바디 타입 / 알림 / 계정 / 동기화 상태 / 건강 데이터 동의 / 데이터 내보내기 / 정보.

## 4. 식단 DB 노출 규칙
- 기기 지역이 한국(KR) → 식약처 DB 우선 + USDA 보조, 그 외 → USDA만. 해외 거주 한국인은 고려하지 않으며 DB 선택 설정은 없다.
- 두 데이터셋은 별도 테이블, 검색 쿼리에서 소스 필터. 출처 표기도 노출된 소스만.

## 5. 데이터 색 규칙
- 의미색: 워밍업·밸런스 이탈 = 주황, PR = 빨강, 프리필 = 회색.
- 차트·매크로 구분: 모노 테마는 단색 + 선 종류, 블루·라임 테마는 색으로 구분(토큰 `data`, `dash`).
